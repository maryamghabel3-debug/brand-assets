## 2. Locked Brand Specifications

### A. RADMAN SILVER 925 (`رادمان سیلور ۹۲۵`)
- **English Wordmark:** French Didot serif (`RADMAN`) with modern geometric sans-serif subtext (`SILVER 925`) and heritage line (`STERLING • MAISON • EST. 2026`).
- **Persian Wordmark:** **Estedad Bold (`استعداد Bold`)** with **S2 secondary sizing** (~50% width of `رادمان`).
- **Tagline Rule:** 
  - Primary Minimal Lockup (`T0`): **No tagline** — reserved for website headers, mobile viewports, and watermarks.
  - Extended Brand Lockup (`T2`): **`اصالت در جزئیات`** — reserved for luxury jewelry boxes, shopping bags, Instagram profile/posts, and "About Us" pages.
- **Palette:** Matte Black (`#0B0B0E`) and Ivory (`#FAF7F2`). 100% clean Shamsa interior on Ivory colorways.

### B. RIDELIN (`رایدلین`)
- **English Wordmark:** Modern chic geometric sans-serif (`RIDELIN`) paired with the Burgundy speed blade horizon line.
- **Persian Wordmark:** **Shabnam Bold (`شبنم Bold`)** paired with the **Option L3 (`360px`)** short horizon speed blade line (`y="52"`).
- **Palette:** Primary Burgundy (`#8A2747`), Dark Bordeaux (`#681B34`), Primary Black (`#0D0D10`), Ivory (`#FAF7F2`), Platinum (`#D9DCE3`), Charcoal Text (`#17171A`).
