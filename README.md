# Brand Assets  
  
Central brand identity repository for two projects under the Radman family:  
  
## 1. RADMAN SILVER 925  
Sterling silver jewelry brand.  
- Domains: radmansilver.ir , radman925.ir  
- Style: Luxury, minimalist, French Haute Joaillerie meets Persian royal design  
  
## 2. RIDELIN  
Motorcycle accessories brand (women-first, unisex products).  
- Domain: ridelin.ir  
- Style: Modern, bold, empowering, sporty-elegant  
  
## Folder Rules  
- /final = approved final logos ONLY  
- /variations = all AI generations and drafts  
- /guidelines = brand book, colors, typography  
- /mockups = packaging and application mockups  
- /favicon = favicon and small-size icons  
- Prefer PNG with transparent background + SVG source files  
- Filenames in English only, lowercase, hyphen-separated (example: logo-dark-v1.svg)
